# promptmaker `v4.0`

**Скилл — промпт-инженер. Пишет готовые системные промпты и пакеты skills для AI-экспертов и агентов под Claude, ChatGPT, Gemini и API.**

> **Версия 4.0** (октябрь 2026) — актуальный релиз. [Что нового](#что-нового-в-v40)

Описываешь, какой эксперт или агент тебе нужен, а скилл выдаёт готовую инструкцию для модели. Саму задачу он не решает: на просьбу «сделай маркетинговую стратегию» он напишет промпт для маркетолога-стратега, которого потом можно вставить в Claude Project, ChatGPT или свой API.

---

## Три режима

| Режим | Как вызвать | Что получишь |
|---|---|---|
| `chat` (по умолчанию) | «сделай промпт для…», «нужен эксперт по…» | Один блок с промптом для копипасты в Claude Project, ChatGPT Project или системное поле |
| `skill` | «сделай skill», «перенеси мой GPT / Gem в skill» | Пакет: короткий `SKILL.md` + справочные файлы, которые модель читает по условию |
| `api` | «для API», «полный пакет», «для своего скрипта» | Промпт + параметры модели + порядок для кэша + 5–10 тестовых примеров |

---

## Чем он отличается от «напиши мне промпт»

- **Правила с областью применимости.** Многие советы по промптам верны только для одной модели: капс вредит новым Claude, но помогает голосовому Grok; «думай шаг за шагом» лишнее для reasoning-моделей OpenAI, но рекомендовано для DeepSeek-R1 на математике. В базе скилла у каждого правила указано, где оно подтверждено, чем и когда проверено.
- **Минимальный достаточный размер.** Каждая строка промпта должна менять поведение модели. Корректору хватит 500–3 000 символов, агенту с инструментами нужно 6 000–12 000.
- **Без устаревших ритуалов.** Скилл не вставляет «перепроверь себя», «думай очень тщательно», «эксперт с 12 годами опыта», не просит модель расписывать рассуждения в ответе: на моделях 2026 года это тратит деньги или ломает ответ.
- **Агентные контракты.** Для агентов скилл прописывает, чем может закончиться работа (готово / заблокировано / нужно подтверждение / кончился бюджет), даёт настойчивость вместе с защитой от зацикливания, бриф для субагентов и защиту от команд внутри писем и документов.
- **Учитывает площадку.** Знает лимиты Claude Projects, ChatGPT, Gemini Skills и Claude Code, а также что Gems и Custom GPTs уходят в конце 2026 года.

---

## Что нового в v4.0

- Все правила перепроверены по гайдам Anthropic, OpenAI, Google, xAI, DeepSeek, Qwen и исследованиям 2025–2026 годов (срез 27.10.2026).
- Новый режим `skill`: перенос GPT и Gem в Skills.
- Отдельный файл `references/models.md` с моделями, параметрами рассуждений, кэшем и лимитами площадок. Он устаревает быстрее правил, поэтому лежит отдельно.
- Убрано: «только позитивные формулировки», «промпт = 5–10% окна контекста», обязательный повтор правил в конце, таблица «оптимального» числа примеров для всех моделей.
- Добавлено: антипаттерны 2026 года, агентные паттерны, блок «как проверить промпт на своих примерах».

## Установка

**Claude Code:**

```bash
git clone https://github.com/syrtsovk/Syrtsovk_toolkit.git ~/syrtsovk-toolkit
ln -s ~/syrtsovk-toolkit/skills/promptmaker ~/.claude/skills/promptmaker
```

**Claude.ai (веб и приложение):** заархивируй папку `promptmaker` в zip и загрузи через Settings → Features → Skills — пошагово в [корневом README](../../README.md#2-claudeai-web--desktop).

После установки просто напиши: «сделай промпт для эксперта по …».

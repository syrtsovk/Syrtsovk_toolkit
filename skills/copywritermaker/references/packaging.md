# Упаковка навыка

Пакет — пять файлов из этапа 4 с правками этапа 5. Упакуй под площадку, которую человек назвал на этапе 1.

## Kimi
Если у тебя есть встроенный навык skill-creator — позови его сам с таким заданием:

```
Создай навык из этих файлов. Ничего не сокращай и не переписывай, справочники сохрани отдельными файлами слово в слово.
Название: <название>. Звать, когда пишу: «<фраза запуска>».
<пять файлов, каждый с путём и полным текстом>
```

В блок вставляй полный текст всех пяти файлов, а не их названия. Новый чат не видит этот разговор.

Не получается позвать сам — дай человеку этот текст целиком в одном блоке и скажи: «Откройте новый чат, напишите / и выберите skill-creator, вставьте этот текст».
После сборки попроси человека запустить навык через «/» на второй тестовой теме.

## Claude (claude.ai, приложение, Claude Code)
Выдай пять файлов. Скажи человеку:
1. Создайте папку с названием навыка, внутри SKILL.md и папку references с четырьмя файлами.
2. Claude.ai: заархивируйте папку в zip и загрузите в Settings → Features → Skills. Claude Code: положите папку в ~/.claude/skills/.

## ChatGPT и другие без навыков
Создайте проект. Текст SKILL.md без шапки — в инструкции проекта, четыре справочника — файлами в проект.

## Перед выдачей
Сверь ещё раз: 7 шагов каркаса на месте, скобок не осталось, тексты человека слово в слово, в шаге 5 есть humanvoice и запасной список.

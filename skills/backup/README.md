# backup

Скилл для ИИ-агентов с доступом к файлам: **Claude Code** и **Codex** (проверено), плюс любая другая папка настроек, которую вы укажете (не проверено). Складывает всё, что вы настроили (скиллы, команды, правила, хуки, агентов, настройки, память проектов, список MCP-серверов без ключей), в **ваш приватный GitHub-репозиторий**. Перед каждым пушем сканирует на секреты.

## Зачем

Всё настроенное лежит у вас на компьютере: `~/.claude`, `~/.codex`. Хорошо, пока папки на месте. Но если аккаунт угонят, придётся заводить другой, а новая установка может начать с пустой папки или затереть прежнюю. То же при переустановке macOS, поломке или потере ноутбука.

С бэкапом это небольшое событие вместо недели восстановления вручную: ставите инструмент, клонируете репозиторий, запускаете один скрипт.

## Что сохраняется и что нет

| Сохраняется | Не сохраняется (намеренно или по природе) |
|---|---|
| Claude Code: скиллы, команды, хуки, агенты, `settings.json`, `CLAUDE.md` из `~/.claude` | Ключи, токены, пароли, `.env`, `*.pem`, `*.key` |
| Claude Code: память проектов (можно отключить) | Входы в аккаунт (`auth.json` и подобное), история чатов и сессий |
| Codex: `AGENTS.md`, скиллы, агенты, хуки из `~/.codex` | Заметки памяти с именем `secret_*` и `*credential*` |
| Списки MCP-серверов Claude Code и Codex (ключи заменены на `<REDACTED>`) | Проекты, память и чаты на стороне сервисов (claude.ai, веб-ChatGPT) |
| Ваша папка настроек другого инструмента (по списку, который вы одобрите) | Код ваших проектов (он в своих репозиториях) |
| Отчёт: какие ваши репозитории не в облаке | |

Копируется **белый список** файлов, а не вся папка. Поэтому `auth.json`, сессии и базы Codex в копию не попадут, даже если лежат рядом.

## Как это защищает

- **Только приватный репозиторий.** Скрипт спрашивает у GitHub, приватный ли он. Публичный: стоп, ничего не записано.
- **Скан секретов** перед каждым коммитом. Находка = стоп. Значение секрета не печатается нигде.
- **Ключи, вписанные прямо в ваши скрипты,** заменяются заглушкой в копии (в оригинале остаются).
- **Восстановление ничего не удаляет.** Если файл отличается, старая версия уезжает в `~/.ai-restore-backup-<дата>/`.

## Где это ломается

- **Взломали и GitHub тоже:** копия уйдёт вместе с ним. Раз в месяц положите архив на внешний диск.
- **Mac выключен:** автозапуск по расписанию не сработает. Страховка: запускайте бэкап руками перед большими изменениями.
- **Ключи не вернутся сами.** После восстановления их надо ввести заново из менеджера паролей (список в `SECRETS-NEEDED.md`).
- **Не проверенный бэкап не бэкап.** Один раз прогоните восстановление в тестовую папку (шаг 8 в `INSTALL.md`).
- **Другие инструменты, кроме Claude Code и Codex, автор не проверял.** Механизм общий (папка → белый список → скан), но структуру их настроек вы подтверждаете сами при установке.

## Установка

Отдайте своему агенту (Claude Code или Codex) ссылку на [INSTALL.md](INSTALL.md) и скажите «установи». Он задаст три вопроса и сделает остальное.

## Состав

```
backup/
├── SKILL.md                  # протокол
├── INSTALL.md                # установка (для агента)
├── config.example.json       # настройки: репозиторий, цели, исключения
├── scripts/
│   ├── backup_snapshot.py    # снимок + отчёт «что не в облаке» + проверка приватности
│   └── secret_scan.py        # поиск секретов в добавленных строках
└── templates/                # файлы, которые кладутся в ваш бэкап-репозиторий
    ├── install.sh            # восстановление
    ├── RESTORE.md            # пошагово «как вернуть»
    ├── SECRETS-NEEDED.md     # что вводится руками
    ├── README.md
    └── gitignore
```

# backup

Команда `/backup` для Claude Code. Складывает всё, что вы настроили (скиллы, команды, хуки, агентов, `settings.json`, `CLAUDE.md`, память проектов, список MCP-серверов без ключей), в **ваш приватный GitHub-репозиторий**. Перед каждым пушем сканирует на секреты.

## Зачем

Всё настроенное лежит у вас на Mac, в папке `~/.claude`. Хорошо, пока она на месте. Но если аккаунт угонят или забанят, придётся заводить другой, а новая установка может начать с пустой папки или затереть прежнюю. То же при переустановке macOS, поломке или потере ноутбука.

С бэкапом это небольшое событие вместо недели восстановления вручную: ставите Claude Code, клонируете репозиторий, запускаете один скрипт.

## Что сохраняется и что нет

| Сохраняется | Не сохраняется (намеренно или по природе) |
|---|---|
| Скиллы, команды, хуки, агенты из `~/.claude` | Ключи, токены, пароли, `.env`, `*.pem`, `*.key` |
| `settings.json`, `CLAUDE.md` | Заметки памяти с именем `secret_*` и `*credential*` |
| Память проектов (можно отключить) | История чатов Claude Code |
| Список MCP-серверов (ключи заменены на `<REDACTED>`) | Проекты, память и чаты на стороне claude.ai (веб) |
| Отчёт: какие ваши репозитории не в облаке | Код ваших проектов (он в своих репозиториях) |

## Как это защищает

- **Только приватный репозиторий.** Скрипт спрашивает у GitHub, приватный ли он. Публичный: стоп, ничего не записано.
- **Скан секретов** перед каждым коммитом. Находка = стоп. Значение секрета не печатается нигде.
- **Ключи, вписанные прямо в ваши скрипты,** заменяются заглушкой в копии (в оригинале остаются).
- **Восстановление ничего не удаляет.** Если файл отличается, старая версия уезжает в `~/.claude-restore-backup-<дата>/`.

## Где это ломается

- **Взломали и GitHub тоже:** копия уйдёт вместе с ним. Раз в месяц положите архив на внешний диск.
- **Mac выключен:** автозапуск по расписанию не сработает. Страховка: запускайте `/backup` руками перед большими изменениями.
- **Ключи не вернутся сами.** После восстановления их надо ввести заново из менеджера паролей (список в `SECRETS-NEEDED.md`).
- **Не проверенный бэкап не бэкап.** Один раз прогоните восстановление в тестовую папку (шаг 8 в `INSTALL.md`).

## Установка

Отдайте своему агенту (Claude Code) ссылку на [INSTALL.md](INSTALL.md) и скажите «установи». Он задаст три вопроса и сделает остальное.

## Состав

```
backup/
├── SKILL.md                  # протокол /backup
├── INSTALL.md                # установка (для агента)
├── config.example.json       # настройки
├── scripts/
│   ├── backup_snapshot.py    # снимок + отчёт «что не в облаке» + проверка приватности
│   └── secret_scan.py        # поиск секретов в добавленных строках
└── templates/                # файлы, которые кладутся в ваш бэкап-репозиторий
    ├── install.sh            # восстановление
    ├── RESTORE.md            # пошагово «как вернуть»
    ├── SECRETS-NEEDED.md     # что вводится руками
    ├── README.md
    └── gitignore
```

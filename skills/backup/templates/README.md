# Бэкап настроек Claude Code

Приватный репозиторий. Здесь копия моих скиллов, команд, хуков, агентов, настроек и памяти проектов из `~/.claude`. Если компьютер умрёт, аккаунт придётся поменять или Claude Code придётся поставить заново, настройки возвращаются по `RESTORE.md`.

**Репозиторий должен оставаться приватным.** Внутри ваши рабочие инструкции и память. Публичным его делать нельзя.

**Дата снимка:** не сделан.

## Что внутри

| Путь | Что |
|---|---|
| `claude-home/skills/`, `commands/`, `hooks/`, `agents/`, `scripts/` | то же, что в `~/.claude`, ссылки заменены обычными файлами |
| `claude-home/CLAUDE.md`, `settings.json` | глобальные правила и настройки |
| `claude-home/projects-memory/` | память проектов |
| `claude-home/claude.json.sanitized` | список MCP-серверов без ключей |
| `install.sh` | установка в `~/.claude` (по умолчанию сухой прогон) |
| `RESTORE.md` | пошагово: как вернуть всё на новом месте |
| `SECRETS-NEEDED.md` | что вводится руками после восстановления |

## Чего здесь нет намеренно

Ключи, токены, пароли, `.env`, файлы `*.pem` и `*.key`, заметки памяти `secret_*`, библиотеки (`node_modules`, `.venv`), история чатов. Перед каждым коммитом скан ищет секреты в добавленных строках.

# Бэкап настроек ИИ-инструментов

Приватный репозиторий. Здесь копия моих скиллов, команд, правил, хуков, агентов, настроек и памяти проектов из `~/.claude` (Claude Code), `~/.codex` (Codex) и других папок, которые я добавил. Если компьютер умрёт, аккаунт придётся поменять или инструмент придётся поставить заново, настройки возвращаются по `RESTORE.md`.

**Репозиторий должен оставаться приватным.** Внутри ваши рабочие инструкции и память. Публичным его делать нельзя.

**Дата снимка:** не сделан.

## Что внутри

| Путь | Что |
|---|---|
| `<цель>-home/` (`claude-home/`, `codex-home/`, ...) | настройки инструмента, ссылки заменены обычными файлами |
| `claude-home/projects-memory/` | память проектов Claude Code |
| `*/claude.json.sanitized`, `*/config.toml.sanitized` | списки MCP-серверов без ключей |
| `backup-manifest.json` | какая цель в какую папку ставится при восстановлении |
| `install.sh` | установка (по умолчанию сухой прогон) |
| `RESTORE.md` | пошагово: как вернуть всё на новом месте |
| `SECRETS-NEEDED.md` | что вводится руками после восстановления |

## Чего здесь нет намеренно

Ключи, токены, пароли, `.env`, файлы `*.pem` и `*.key`, входы в аккаунт, заметки памяти `secret_*`, библиотеки (`node_modules`, `.venv`), история чатов. Перед каждым коммитом скан ищет секреты в добавленных строках.

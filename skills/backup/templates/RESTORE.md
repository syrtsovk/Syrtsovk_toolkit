# Как вернуть настройки ИИ-инструментов после потери компьютера, аккаунта или чистой установки

Коротко: ставите инструмент (Claude Code, Codex), скачиваете этот репозиторий, запускаете один скрипт, и скиллы, команды, хуки, агенты, настройки и память проектов на месте. Ключи и входы в сервисы возвращаете руками по списку.

Время: 30-60 минут, большая часть уходит на ключи и входы.

## Если вы просто ставите другой аккаунт на том же Mac

Заводить новый аккаунт и входить в него можно сразу. Главное: **сначала скачайте этот репозиторий** (шаг 2), а установку (шаг 3) запустите уже под новым аккаунтом. Скрипт ничего не удаляет и каждую отличающуюся версию файла кладёт в `~/.ai-restore-backup-<дата>/`: ничего, что успел настроить новый аккаунт, не пропадёт.

## Шаг 1. Поставить Claude Code и инструменты

```bash
# Homebrew, git, gh, python3
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install git gh python
# Claude Code и/или Codex: по официальной инструкции инструмента, затем войти в аккаунт
claude          # или codex
gh auth login   # войти в GitHub (тот, где лежит бэкап)
```

## Шаг 2. Скачать бэкап

Подставьте адрес своего приватного репозитория:

```bash
git clone https://github.com/<ваш-логин>/<имя-репозитория>.git ~/ai-backup
cd ~/ai-backup
```

## Шаг 3. Поставить настройки

```bash
./install.sh            # сухой прогон: покажет, что будет сделано, ничего не пишет
./install.sh --apply    # реальная установка: каждая цель в свою папку (~/.claude, ~/.codex, ...)
```

- Если в `~/.claude` уже что-то было, старые версии изменённых файлов окажутся в `~/.ai-restore-backup-<дата>/`.
- Запускать повторно безопасно: одинаковые файлы не трогаются.
- Файлы `*.sanitized` (списки MCP-серверов) скрипт **не ставит**: в них вместо ключей заглушки.
- Если имя пользователя на новом Mac другое, скрипт предупредит о путях в `settings.json`. Поправьте их руками.

## Шаг 4. Восстановить ключи

Откройте `SECRETS-NEEDED.md` и пройдите по списку: MCP-серверы по образцу `claude-home/claude.json.sanitized` и `codex-home/config.toml.sanitized`, ключи из менеджера паролей.

## Шаг 5. Клонировать проекты

Код проектов в бэкап не входит, он в своих репозиториях. Клонируйте их в те же места, что раньше, тогда пути в настройках и в памяти совпадут. Файлы `.env` в git не хранятся, значения берите из менеджера паролей.

## Шаг 6. Память проектов

Установка из шага 3 уже положила заметки в `~/.claude/projects/<проект>/memory/` (существующие не перезаписала). Имя папки проекта это путь к нему, где `/` и пробелы заменены на `-`. Если путь проекта на новом Mac другой, просто скажите Claude: «Прочитай `~/ai-backup/claude-home/projects-memory/<папка>` и продолжаем».

## Шаг 7. Проверка

Откройте инструмент и убедитесь, что ваши команды и скиллы в списке. Запустите бэкап (в Claude Code `/backup`, в Codex «сделай бэкап настроек по скиллу backup»), чтобы сделать первый снимок уже с нового места.

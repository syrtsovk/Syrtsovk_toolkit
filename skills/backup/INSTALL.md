# Установка /backup

> **Эта страница написана для AI-агента.** Если вы человек: отдайте своему агенту (Claude Code) ссылку на этот файл и скажите «установи». Он сделает всё сам и задаст вам три вопроса. Руками тоже можно, команды ниже работают в терминале.

---

## Агенту: прочитай целиком, потом выполняй

Скилл работает на **Mac или Linux, в Claude Code** (ему нужны файлы `~/.claude`). В веб-версии Claude.ai он не заработает. Если ты там, скажи об этом человеку и остановись.

Что получится: папка `~/.claude/skills/backup` (сам скилл) и **отдельный приватный репозиторий** на GitHub человека, куда `/backup` складывает копию настроек.

**Главное правило: репозиторий бэкапа создаётся только приватным.** Внутри будут скиллы, команды и память человека. Если репозиторий окажется публичным, остановись и скажи об этом человеку.

---

## Шаг 0. Проверить, что есть чем работать

```bash
git --version && gh --version && python3 --version && rsync --version | head -1
gh auth status
```

- Нет `gh` или не выполнен вход: `brew install gh && gh auth login`. Без входа в GitHub облако не получится, остановись и объясни человеку.
- Нет `git`, `python3` или `rsync`: поставь (`brew install git python rsync`) или скажи человеку.

## Шаг 1. Поставить скилл

```bash
mkdir -p ~/.claude/skills
git clone --depth 1 https://github.com/syrtsovk/Syrtsovk_toolkit.git /tmp/syrtsovk-toolkit
cp -R /tmp/syrtsovk-toolkit/skills/backup ~/.claude/skills/backup
rm -rf /tmp/syrtsovk-toolkit
ls ~/.claude/skills/backup
```

Должно быть: `SKILL.md`, `INSTALL.md`, `README.md`, `config.example.json`, `scripts/`, `templates/`.

## Шаг 2. Приватный репозиторий для бэкапа

**Спроси человека (вопрос 1):** «Как назвать репозиторий бэкапа? По умолчанию `claude-backup`.»

```bash
cd ~
gh repo create claude-backup --private --clone      # подставь имя
gh repo view claude-backup --json isPrivate -q .isPrivate     # должно быть true
```

Если `gh repo create` вернул ошибку «already exists»: репозиторий уже есть. Клонируй его (`gh repo clone`) и **проверь приватность** той же командой. Не `true`: стоп.

Клон должен оказаться в `~/claude-backup`. Назвали иначе: запомни путь для шага 4.

## Шаг 3. Положить шаблоны в репозиторий

```bash
S=~/.claude/skills/backup/templates
B=~/claude-backup
cp "$S/install.sh" "$S/RESTORE.md" "$S/SECRETS-NEEDED.md" "$S/README.md" "$B/"
cp "$S/gitignore" "$B/.gitignore"
chmod +x "$B/install.sh"
```

В `README.md` бэкап-репозитория поправь первую строку под человека, если нужно. Строку `**Дата снимка:**` не трогай: скрипт обновляет её сам.

## Шаг 4. Настройки

**Спроси человека (вопрос 2):** «Брать ли в бэкап память проектов? Это заметки, которые Claude накопил про ваши проекты. Они полезны при восстановлении, но могут содержать личное. Репозиторий приватный. По умолчанию да.»

**Спроси человека (вопрос 3):** «Где у вас лежат git-репозитории с проектами? (например `~/Projects`). Я покажу в отчёте, какие из них не отправлены в облако и пропадут, если Mac умрёт.»

```bash
cp ~/.claude/skills/backup/config.example.json ~/.claude/skills/backup/config.json
```

Отредактируй `~/.claude/skills/backup/config.json`:

| Поле | Что вписать |
|---|---|
| `repo` | путь к клону из шага 2, по умолчанию `~/claude-backup` |
| `include_memory` | `true` или `false` по ответу на вопрос 2 |
| `scan_dirs` | список папок из вопроса 3, например `["~/Projects"]`; `null` = поискать в типовых |
| `extra_excludes` | пока пусто, пригодится, если скан найдёт секрет в файле |

`config.json` не содержит секретов, он попадёт в бэкап вместе со скиллом.

## Шаг 5. Первый сухой прогон

```bash
python3 ~/.claude/skills/backup/scripts/backup_snapshot.py
```

Ничего не пишет. Покажи человеку вывод: сколько файлов попадёт в снимок и какие репозитории не в облаке. Спроси: «Всё верно, делаем первый бэкап?»

## Шаг 6. Первый бэкап

Выполни `/backup` по протоколу из `SKILL.md`: снимок, скан, коммит, пуш. Если скан нашёл секреты, действуй по шагу 2 из `SKILL.md`, не пушь.

Проверка в конце: `git -C ~/claude-backup log --oneline | head -3` показывает коммит, и он же виден в облаке (`git -C ~/claude-backup rev-parse --short HEAD @{u}` совпадает).

## Шаг 7. Расписание (необязательно)

Бэкап полезен, если делается регулярно. Раз в неделю, например в понедельник утром.

- **Приложение Claude (десктоп):** создай регулярную задачу (Scheduled tasks) с промптом `/backup`. Работает, пока Mac включён и приложение открыто.
- **Без приложения:** строка в `crontab -e` вида `0 10 * * 1 cd ~ && claude -p "/backup"`. Проверь вручную один раз, прежде чем полагаться.

Не получилось: ничего страшного, просто запускайте `/backup` руками после больших изменений.

## Шаг 8. Проверить, что восстановление работает

Это самое важное: бэкап, который ни разу не пробовали разворачивать, это надежда, а не бэкап.

```bash
cd ~/claude-backup
TARGET_HOME=/tmp/restore-test ./install.sh --apply
ls /tmp/restore-test/.claude
rm -rf /tmp/restore-test
```

Должны появиться `skills/`, `commands/`, `settings.json`. Дальше инструкция для настоящего восстановления лежит в `RESTORE.md` бэкап-репозитория.

## Итог для человека (скажи в конце)

- Где скилл: `~/.claude/skills/backup`, команда `/backup`.
- Где копия: ваш приватный репозиторий (адрес).
- Что в неё не попадает: ключи, `.env`, история чатов, то, что хранится на стороне claude.ai.
- Что делать дальше: запускать `/backup` раз в неделю; перед сменой аккаунта или переустановкой Claude Code запустить обязательно.
